Claude Code 快捷键速查

按 context（生效场景） 分组 —— 同一个键在不同界面含义不同，只有处于该场景时绑定才生效。
meta 在 macOS 终端通常是 Option（需开启 "Use Option as Meta"），与单列出的 cmd 不是一回事。
▸ 表示「和弦」：先按前一组，松开，再按后一组 —— 例如 ctrl+x ▸ ctrl+k。或 表示多个等价键位。

配置文件 ~/.claude/keybindings.json　·　文档 code.claude.com/docs/en/keybindings 键位刻意兼容三套肌肉记忆：方向键 · vim(hjkl/g/G) · emacs(ctrl+n/ctrl+p)
